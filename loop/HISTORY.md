# HISTORY

Append-only log of AEGIS prompt-loop iterations. **Never edit or delete existing
rows** — add a new row at the bottom for each completed iteration.

Columns:
- **Iteration** — the iteration number `n`.
- **Task ID** — the stable `TASK_ID` from that iteration's TASK block.
- **Task Title** — a short name for the task.
- **Status** — the reported `STATUS`: `READY`, `BLOCKED`, or `DONE`.
- **Summary** — one line describing what actually happened.

| Iteration | Task ID | Task Title | Status | Summary |
